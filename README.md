## 📂 Projects

### 1. 📚 Excel Basics & Formulas

This project focuses on practicing **basic and advanced Excel formulas** using structured datasets.

**Key Areas:**

* Basic Excel operations
* Working with dates and months
* `COUNT`
* `SUM`
* `AVERAGE`
* `MIN`
* `MAX`
* `IF`
* `SUMIF`
* Salary calculations
* Incentive calculation
* TDS calculation
* PF calculation
* Net salary calculation
* Data classification
* Text concatenation
* Email generation

---

### 2. 🚗 Car Brands & Car Details

This project contains **car-related data** and uses Excel for organizing, analyzing, and visualizing the dataset.

**Dataset:** Car Details from CarDekho

**Data Visualisation using:**

* Car details and specifications
* Manufacturing year analysis
* Pivot table analysis
* Seller type analysis
* Dealer vs Individual seller comparison
* Year-wise car count

**Charts/Pivot Table Created:**

* Number of Cars by Year
* Seller Type Distribution by Year
